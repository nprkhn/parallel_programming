# Лабораторная работа №4  
## Измененные файлы
`generate_matr.py`, `main.py`, `cuda_multiply.py`, `graph1.png`, `graph2.png`, `stats.txt`  
## Основные файлы
`generate_matr.py` - генерация двух квадратных матриц одинакового размера  
`cuda_multiply.cu` - перемножение двух матриц с помощью CUDA на языке C++  
`verify.py` - сравнение результата перемножения матриц на C++ со значением, полученным с помощью библиотеки numpy  
## Описание программы
Для выполнения программы необходимо написать в консоль `python main.py`  
Результаты работы программы с разными размерами матриц (200, 400, 800, 1600, 2000) и разными блоками приведены в файле `stats.txt`  

`graph1.png` - график зависимости времени умножения от размера матрицы и конфигурации блоков CUDA  
`graph2.png` - ускорение умножения матриц по сравнению с последовательной версией  
## Вывод
Результаты, полученные в ходе выполнения данной лабораторной работы, показывают, что примененный метод перемножения матриц с помощью CUDA является эффективным при оптимальном выборе конфигурации блоков и размера матрицы. Программа показала значительное ускорение по сравнению с последовательным методом.
