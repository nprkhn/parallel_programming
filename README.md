# Лабораторная работа №3
## Измененные файлы
`mul_matrix.cpp`, `main.py`  
## Основные файлы
`generate_matr.py` - генерация двух квадратных матриц одинакового размера  
`mul_matrix.cpp` - перемножение двух матриц на языке C++ с использованием технологии MPI
`verify.py` - сравнение результата перемножения матриц на C++ со значением, полученным с помощью библиотеки numpy  
## Описание программы
Для выполнения программы необходимо написать в консоль `python main.py`  
Результаты работы программы с разными размерами матриц (200, 800, 1000, 1200, 1600, 2000) и разными количествами ядер(1, 2, 4, 8) приведены в файле `stats.txt`  
 
`graph1.png` - график зависимости времени умножения от числа ядер  
`graph2.png` - график ускорения параллельного умножения  
`graph3.png` - график эффективности параллельного умножения  
## Вывод
Результаты, полученные в ходе выполнения данной лабораторной работы, показывают, что примененный метод перемножения матриц с помощью применения технологии распараллеливания программ MPI значительно сокращает время работы программы. Также результаты показывают, что для достижения наибольшей эффективности следует выбирать оптимальное количество ядер для соответсвующих размеров матриц (так для меньшего размера матриц лучше использовать меньшее количество ядер).
