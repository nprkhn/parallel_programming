# Лабораторная работа №1
## Основные файлы
`generate_matr.py` - генерация двух квадратных матриц одинакового размера  
`mul_matrix.cpp` - перемножение двух матрци на языке C++  
`verify.py` - сравнение результата перемножения матриц на C++ со значением, полученным с помощью библиотеки numpy  
## Описание программы
Для выполнения программы необходимо написать в консоль `python main.py`  
Результаты работы программы с разными размерами матриц (200, 400, 600, 800, 1000) приведены в файле `stats.txt`  

`program_run.png` - пример работы программы для размера матрицы 200  
`graphs.png` - графики зависимостей  
## Вывод
Результаты, полученные в ходе выполнения данной лабораторной работы, показывают, что примененный метод перемножения матриц является неэффективным для больших размеров. Чтобы это исправить необходимо применять метод распараллеливания программы.
