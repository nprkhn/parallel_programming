# Лабораторная работа №2
## Основные файлы
`generate_matr.py` - генерация двух квадратных матриц одинакового размера  
`mul_matrix.cpp` - перемножение двух матриц на языке C++ с использованием распараллеливания по технологии OpenMP  
`verify.py` - сравнение результата перемножения матриц на C++ со значением, полученным с помощью библиотеки numpy  
## Описание программы 
Для выполнения программы необходимо написать в консоль `python main.py`    
Результаты работы программы с разными размерами матриц (200, 400, 600, 800, 1200, 1600, 2000) и с разными количествами потоков(1, 2, 4, 8) приведены в файле `stats.txt`  
  
`graph1.png` - график зависимости время умножения матриц от числа потоков  
`graph2.png` - график ускорения параллельного алгоритма  
## Вывод
Результаты, полученные в ходе выполнения данной лабораторной работы, показывают, что примененный метод перемножения матриц c помощью распараллеливания программы по технологии OpenMP существенно сокращает время выполнения программы. Однако для матриц малого размера применение большого числа потоков является неэффективным. Это подчеркивает важность выбора наиболее оптимального количества потоков в зависимости от размера матриц.
