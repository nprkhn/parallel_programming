# Лабораторная работа №5
## Измененные файлы
`graph1.png`, `graph2.png`, `graph3.png`, `stats.txt`  
## Основные файлы
`generate_matr.py` - генерация двух квадратных матриц одинакового размера  
`mul_matrix.cpp` - перемножение двух матриц на языке C++ с использованием технологии MPI
`verify.py` - сравнение результата перемножения матриц на C++ со значением, полученным с помощью библиотеки numpy  
## Описание программы  
Результаты работы программы с разными размерами матриц (200, 800, 1600, 2000) и разными количествами ядер(1, 2, 4, 8) приведены в файле `stats.txt`  
 
`graph1.png` - график зависимости времени умножения от числа ядер  
`graph2.png` - график ускорения параллельного умножения  
`graph3.png` - график эффективности параллельного умножения  
## Вывод
В ходе данной лабораторной работы была запущена программа из лабораторной работы №3 на суперкомпьютере "Сергей Королёв". Результаты демонстрируют наглядную эффективность работы программы с большими размерами матриц (чем больше размер матрицы и количество ядер - тем больше эффективность).
